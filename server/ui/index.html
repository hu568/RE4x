关于 SD Enhance v2.3.0

独立的 Stable Diffusion 图片后期处理工具。基于 Real-ESRGAN 的 realesrgan-ncnn-vulkan 引擎 + ffmpeg 两步管线: 模型固定 4x 放大 → ffmpeg 缩放到目标倍率。

  • 单张图片、批量、目录批量、视频单命令放大(无中间帧)
  • 支持 1–8x 比例放大或精确目标尺寸
  • 支持双模型混合(ffmpeg blend)
  • 本地处理,无需上传,无需联网

引擎:realesrgan-ncnn-vulkan · 模型自动探测 tools/models/
